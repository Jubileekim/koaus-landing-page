# Image assets

The shopping homepage uses `koaus-hero-collection.jpg`, an original generated product still life created for this project.

The `product-*.jpg` and `product-*.png` files are educational MVP references downloaded from the linked 29CM and Ohouse product listings. Product and image rights belong to their respective brands and sellers. Replace these files with authorized koaus brand assets before commercial use.

To replace a placeholder later:

1. Add an optimized `.webp` or `.avif` file to this folder.
2. Update the matching `.product-image` or hero visual markup in `index.html` / `js/main.js`.
3. Add meaningful `alt` text when the image communicates product information. Use an empty `alt=""` only for decorative images.
