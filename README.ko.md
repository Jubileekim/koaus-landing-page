# koaus launch studio

[English](README.md) | [한국어](README.ko.md)

**미국 크리에이터·UGC·커머스 파일럿으로 한국 브랜드의 실제 시장 가능성을 검증하는 반응형 B2B 랜딩페이지입니다.**

> 큰 비용과 재고를 먼저 투입하기 전에, 작은 시장 신호부터 확인합니다.

## 프로젝트 목표

미국 진출을 고민하는 한국의 중소·신생 브랜드가 다음 질문에 답할 수 있도록 설계했습니다.

- 미국의 어떤 고객이 제품에 반응하는가?
- 어떤 메시지와 콘텐츠가 관심과 신뢰를 만드는가?
- 조회와 관심이 클릭·쿠폰·구매 신호로 이어지는가?
- 다음 투자를 확대할지, 수정할지, 중단할지 판단할 수 있는가?

koaus는 크리에이터 검색, UGC 제작, 커머스 실행을 따로 보여주지 않고 하나의 검증형 파일럿 흐름으로 연결합니다.

## 주요 화면 구성

1. **UGC 영상 모자이크 히어로** — 한국 브랜드의 미국 시장 검증 메시지
2. **Problem** — 고객·콘텐츠·구매 전환의 불확실성
3. **Solution** — Creator · UGC · Commerce 모듈
4. **How It Works** — Diagnose → Match → Launch → Measure
5. **Results & Metrics** — 콘텐츠·고객·커머스·의사결정 지표
6. **Pricing** — Starter / Validation / Commerce 패키지
7. **Rate Card & Add-ons** — 크리에이터 1인 단가와 선택 옵션
8. **First Launch Event** — 첫 파일럿 파트너 프로모션
9. **U.S. Launch Inquiry** — 패키지·예산·검증 목표를 포함한 문의 폼

## 구현 기능

- 한국어/영어 전환 및 선택 상태 저장
- 데스크톱·태블릿·모바일 반응형 레이아웃
- 모바일 메뉴
- Intersection Observer 기반 등장 애니메이션
- 화면 밖 UGC 영상 재생 중지 및 모션 감소 설정 대응
- 패키지 비교 / 크리에이터 단가 / 추가 옵션 탭
- 패키지 버튼 클릭 시 문의 폼 자동 선택 및 이동
- 검증 목표 선택을 포함한 폼 유효성 검사
- 문의 내용을 `localStorage`에 저장하는 프런트엔드 MVP
- 수출바우처 안내 페이지
- 별도 koaus shop 및 상품·소개 페이지

## 가격 관련 주의사항

화면에 표시된 패키지 금액, 크리에이터 단가, 할인율, 기간과 샘플 성과 수치는 **과제용 MVP 가안**입니다.

- 모든 금액은 VAT 별도입니다.
- 제품 제공비, 한국→미국 배송비, 관세, 광고 집행비는 포함되지 않습니다.
- 실제 견적은 크리에이터 규모, 카테고리, 콘텐츠 난이도와 사용권 조건에 따라 달라질 수 있습니다.
- 실제 캠페인 성과나 확보된 크리에이터 네트워크로 오해되지 않도록 샘플 데이터임을 명시했습니다.

## 로컬 실행

별도의 빌드나 패키지 설치가 필요하지 않습니다.

```bash
python3 -m http.server 5500
```

브라우저에서 다음 주소를 엽니다.

```text
http://127.0.0.1:5500/
```

## 프로토타입 한계

- 문의 폼은 서버나 이메일 서비스와 연결되어 있지 않으며 현재 브라우저에만 저장됩니다.
- 공개 전 Formspree, Tally, Google Forms 또는 자체 백엔드를 연결해야 합니다.
- 영상과 이미지 자산은 공개·상업적 사용 전 권리 범위를 다시 확인해야 합니다.
- 패키지 가격, 제공 범위, 사용권과 성과 수수료는 실제 계약 단계에서 별도로 확정해야 합니다.
